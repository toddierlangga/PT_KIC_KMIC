PT KIC & KMIC — Website Source Code
Versi 25 Oktober 2026

CARA MENJALANKAN
1. Ekstrak ZIP ini.
2. Buka index.html di browser, atau buka folder PT_KIC_KMIC melalui VS Code dan gunakan Live Server.
3. Tidak memerlukan npm install atau database.

FILE UTAMA
index.html: konten dan struktur website.
styles.css: tampilan, logo, dan tata letak responsif.
script.js: menu serta galeri drone interaktif.
drone-data.js: data lokasi dan foto drone.
assets/: seluruh logo, peta, foto, dan gambar website.

REVISI TERBARU

HOSTING
